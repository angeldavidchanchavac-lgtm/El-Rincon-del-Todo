Proyectos Estudiantiles

Portafolio Web Personal

Desarrollar una página propia utilizando HTML, CSS y estructuras lógicas para mostrar proyectos completados, habilidades técnicas y una presentación profesional ante el mundo digital.

Aplicación de Notas (CRUD)

Un sistema dinámico básico que permite Crear, Leer, Actualizar y Borrar registros. Es el pilar fundamental para aprender a estructurar la lógica de bases de datos y persistencia.

Automatizador de Tareas

Escribir scripts lógicos enfocados en resolver flujos monótonos o repetitivos del sistema operativo, como renombrar archivos en masa, organizar carpetas o limpiar registros del equipo.

Dashboard de Análisis de Datos

Procesar un volumen de datos reales o simulados a través de un panel visual interactivo con gráficas ordenadas, ideal para dominar la interpretación estadística y analítica.

Gestor de Finanzas Personales

Un software interactivo diseñado para registrar ingresos, egresos y calcular balances automáticos mensuales, excelente para dominar operaciones aritméticas y manejo de flujos de dinero.

Simulador de Torneos

Un programa lógico estructurado para emparejar participantes, gestionar estadísticas en tiempo real, almacenar tablas de posiciones y automatizar fases de eliminación en base a reglas dinámicas.
